# Requirements

## 1. Overview

《最后一杯大作战 / The Last Cup Run》是一款约 45 秒的竖屏互动视频游戏：初始画面只有粉色兔子与最后一杯限定奶茶，玩家在 UMe 配送车内依次点亮五件异常物品，观看五位家族成员分别登场的搞笑事故，最后解锁全家族接力护送的高潮片段。

## 2. Visual Design

- 玩家：熟悉或第一次接触 UMe 的移动端用户；单局 40-55 秒，单手游玩。
- 情绪承诺：轻松、热闹、越忙越乱，但家族总能一起把事情办成。
- 画面结构：9:16 竖屏配送车内部为持续主场景；初始状态只出现粉色兔子与最后一杯奶茶，五个热点是车内的西瓜安全带、制冷拉杆、绿色毛线帽、芒果色小票和飘起的珍珠，不提前展示其他家族成员。
- 交互层：未发现热点以轻柔果冻波纹提示；已观看热点变为完成印记；视频播放期间隐藏热点并显示短字幕。
- 主要素材：1 张粉色兔子主画面、5 张单角色分支尾帧、1 张粉色兔子接杯高潮尾帧、1 张顾客接杯微距结算图、6 段约 5 秒视频、1 张 1:1 正式海报。
- 资产生成：主画面和每个分支镜头必须以对应角色的单独参考图直接生成完整场景，不允许把透明角色 PNG 粘贴到摄影背景上作为最终画面。
- 角色必须遵循 `/Users/yin/code/games/memory/ume_mascot_game_brand.md` 的名称差异记录与轮廓锚点；粉色兔子在合作方确认前，游戏内统称 `UMe`。
- 支持中文与英文；中文为默认检测语言，英文文案允许比中文长 40%，按钮和字幕不得截断。
- UI 触控目标不小于 44 × 44 CSS px，不使用 Emoji 作为功能图标，并支持 `prefers-reduced-motion`。

## 3. Game Mechanics

- 初始状态：展示配送车主画面、标题、第一步提示与 5 个热点；完成数为 0/5。
- 热点数量：5 个物件热点，分别预示 MelonMick、LemonShark、GuacPiggy、MangoChick、BubblePearl；角色仅在对应分支片段开始后出现。
- 热点播放：玩家按下热点后，同帧产生按压反馈并进入视频状态；每段视频目标时长 4.5-5.5 秒。
- 字幕：片段开始后 700 ms 淡入；视频结束后尾帧与字幕保持 1,500 ms，其中最后 450 ms 完成回到主画面的交叉淡化。
- 进度：首次观看一个热点时完成数 +1；重复观看允许，但不重复增加进度。
- 高潮解锁：首次观看完 5 个热点后，等待 500 ms，显示“护住最后一杯”高潮按钮。
- 高潮片段：目标时长 5.0-6.0 秒；字幕在 2,800 ms 出现；结束后保持尾帧 2,800 ms，再进入结算。
- 视频失败：若视频加载或解码失败，显示对应尾帧 3,200 ms，仍按相同逻辑计入完成。
- 预加载：主画面显示后预加载 5 段分支视频；高潮视频在完成 3 个热点后预加载。
- 特效：热点按压 180 ms 果冻收缩；首次完成产生 6-10 个圆形珍珠粒子，持续 650 ms；全部完成时配送杯晃动 420 ms 并出现一次黄色速度线。
- 无积分、生命、排行榜或网络生成环节；视频与图片均为随包发布的静态素材。

## 4. Controls

- Pointer / Touch：热点与主行动按钮使用 `onPointerDown`；一次按下只触发一次，视频播放期间所有热点禁用。
- Keyboard：热点按 DOM 顺序可聚焦；`Enter` 或 `Space` 触发；焦点环清晰可见。
- 音量：声音按钮使用 `onClick`，在静音/有声之间切换并更新可访问标签。
- 重玩：结算页“再送一杯”按钮使用 `onPointerDown`，立即清空本局进度并返回初始主画面。

## 5. Win / Lose Conditions

- 胜利：观看完 5 个角色片段并播放高潮片段后完成游戏。
- 本游戏没有失败状态；错乱、碰撞、洒落均是可恢复的喜剧表演，不惩罚玩家。
- 结算画面展示顾客双手接到奶茶的微距、完成文案与“再送一杯”按钮；无需全家福。
- 视频不可用不阻塞胜利：静态尾帧回退仍可完成对应热点和整局流程。

## 6. Sound Effects

- 热点按下：柔和木鱼/泡泡点击，正弦波 520 Hz 降至 410 Hz，80 ms，峰值音量 0.10。
- 首次完成：三角波 620/780 Hz 双音上行，各 70 ms，间隔 45 ms，峰值音量 0.08。
- 重复观看：正弦波 460 Hz，60 ms，峰值音量 0.06。
- 全部点亮：三角波 520/660/830 Hz 三音上行，总时长 260 ms，峰值音量 0.11。
- 高潮冲线：低频正弦 150-240 Hz 上滑 280 ms，叠加 900 Hz 短脉冲，峰值音量 0.10。
- 完成：正弦与三角混合的 660/830/990 Hz 和弦，420 ms，峰值音量 0.10。
- 音频仅在首次用户交互后创建或恢复；音频失败不影响游戏；静音和系统减少动态模式均保留明确视觉反馈。
